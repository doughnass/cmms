ลิงก์ด่วน (ระบบบำรุงรักษา)

หน้านี้รวบรวมลิงก์ด่วนสำหรับการทดสอบและจัดการระบบบำรุงรักษา — ใช้ดูแบบฟอร์มการนัดหมาย กำหนดความสามารถของวันสำหรับการบำรุงรักษา และจัดการข้อมูลช่าง

ส่วนติดต่อ (UI)
  • หน้าแผนการบำรุงรักษา — เลือกวันที่นัดหมายสำหรับอุปกรณ์ที่ใกล้ครบกำหนด
  • กำหนดความสามารถต่อวัน — กำหนดจำนวนงานบำรุงรักษาต่อประเภทในแต่ละวัน
  • รายการนัดหมาย — ดู/ลบ/จัดการนัดหมายที่บันทึกไว้
ข้อมูลช่าง
  • รายการช่าง — แก้ไข/เพิ่มข้อมูลช่าง
  • ตารางการมาทำงานของช่าง — บันทึกการมาทำงานหรือการลา
ผู้ดูแลระบบ / API
  • Admin: ข้อมูลช่าง
  • Admin: ตารางช่าง
  • Admin: ความสามารถต่อวัน
  • Admin: นัดหมาย
  • ตัวอย่าง API: ตรวจสอบความจุ
  • ตัวอย่าง API: ดึงช่างตามวันที่
